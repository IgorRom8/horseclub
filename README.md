# Конный клуб — сайт

Лендинг и внутренние страницы конного клуба: услуги, инфраструктура, тренеры, конюшни, контакты, форма заявки. Контент части страниц может подтягиваться из PostgreSQL (Prisma), при недоступности БД используются статические заготов из кода.

## Технологии

| Область | Стек |
|--------|------|
| Фреймворк | **Next.js 15** (App Router) |
| UI | **React 19**, **TypeScript** |
| Стили | **Tailwind CSS** |
| БД (опционально) | **PostgreSQL** + **Prisma 6** (страницы CMS, галерея; заявка с сайта в БД не пишется) |
| Деплой | **Vercel** (в `web/vercel.json` — команды установки/сборки для монорепозитория) |

Дополнительно: встраиваемая карта Яндекса (`NEXT_PUBLIC_YANDEX_MAP_EMBED`), опциональный вебхук заявок (`CONTACT_WEBHOOK_URL`), скрипты синхронизации изображений (`web/scripts/`).

## Структура репозитория

- **`/`** — корень workspaces (`npm workspaces`: пакет `web`)
- **`web/`** — Next.js-приложение (исходники, `prisma/`, `public/`)

Команды удобнее запускать из **корня**: они проксируются в `web`.

## Локальный запуск

Требования: **Node.js** (рекомендуется актуальный LTS, совместимый с Next.js 15).

1. Клонировать репозиторий и перейти в каталог проекта.

2. Установить зависимости из корня:

   ```bash
   npm install
   ```

3. Переменные окружения — скопировать пример и при необходимости поправить:

   ```bash
   copy web\.env.example web\.env.local
   ```

   На macOS/Linux:

   ```bash
   cp web/.env.example web/.env.local
   ```

   Минимально для «просто открыть сайт» достаточно публичных `NEXT_PUBLIC_*`.  
   **`DATABASE_URL`** нужен, если хотите CMS/галерею из БД; форма «Заявка» работает и без PostgreSQL.

4. (Опционально) база и демо-данные:

   ```bash
   npm run db:push
   npm run db:seed
   ```

5. Режим разработки:

   ```bash
   npm run dev
   ```

   Сайт по умолчанию: [http://localhost:3000](http://localhost:3000).

6. Продакшен-сборка локально:

   ```bash
   npm run build
   npm run start
   ```

## Развёртывание (Vercel)

1. Подключить репозиторий к Vercel, **корень проекта** или каталог `web` — в зависимости от настроек; в репозитории есть `web/vercel.json` с логикой `installCommand` для монорепы.

2. В панели Vercel задать переменные как в `web/.env.example` (в т.ч. `DATABASE_URL`, если используется БД).

3. Сборка: `npm run build` (на корне или в `web` — как настроите интеграцию).

После деплоя проверьте форму заявки, карту и ссылки WhatsApp/Telegram.

## Полезные скрипты

| Команда (из корня) | Назначение |
|--------------------|------------|
| `npm run dev` | Разработка |
| `npm run build` / `npm run start` | Сборка и продакшен-старт |
| `npm run lint` | ESLint |
| `npm run db:generate` / `db:push` / `db:seed` | Prisma (после настройки `.env.local`) |

В каталоге `web`: `npm run images:sync` — синхронизация картинок из корневой папки `images/` (см. скрипт в репозитории).
